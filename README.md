# Space Marine 2 Progression APP

A Discord automatic progression system.

## Features
- AAR points system
- Rank progression system
- Operation / Stratagem / Siege / PvP reports
- Gene seed tracking
- Challenge system
- embed grid reporting system

## Setup

1. Install dependencies
2. Set environment variable
3. Change DB_File to: database.db (currently set for Render)
4. Run

## Requirements
- Python 3.10+
- discord.py 2.x

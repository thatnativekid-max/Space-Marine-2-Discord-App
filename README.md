# Space Marine 2 Progression APP

A Discord automatic progression system.

## Features
- AAR points system
- Rank progression system
- Operation / Stratagem / Siege / PvP reports
- Gene seed tracking
- Challenge system
- embed grid reporting system

## Setup

1. Install dependencies
2. Set environment variable
3. Change DB_File to: database.db (currently set for Render)
4. Run

## Requirements
- Python 3.10+
- discord.py 2.x

## Command List
/edit_aar_points (add or subtract points)
/player_card (display player card)
/approve_challenge (approve rank challenge)
/operation_report (operation embed display)
/stratagem _report (stratagem embed display)
/siege_report (siege mode embed display)
/pvp_report (pvp embed display)
